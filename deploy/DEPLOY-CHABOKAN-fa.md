# راهنمای استقرار روی چابکان (Chabokan) — لندینگ + اپ رسا

این راهنما ستاپ پیشنهادی و نهایی برای انتشار عمومی رسا روی پلتفرم ابری چابکان است:
**دو سرویس مجزا، یک دامنه.** برای راهنمای عمومی (VPS شخصی یا Liara) به
[`DEPLOY-fa.md`](DEPLOY-fa.md) مراجعه کنید.

## معماری

```
        ┌─ https://<دامنه>.ir          ← لندینگ (همین پوشهٔ استاتیک rasa-standalone)
دامنه ──┤        سرویس استاتیک (هاست ReactJS/استاتیک چابکان)
        │
        └─ https://app.<دامنه>.ir     ← اپ PWA (ریپوی rasa — Next.js)
                 سرویس «هاست Next» چابکان (Node.js)
```

چرا زیردامنهٔ جدا برای اپ؟ مانیفست PWA نسخهٔ ۱٫۰٫۰ با `scope: "/"` تست و تأیید شده؛
میزبانی اپ روی زیردامنهٔ اختصاصی **بدون هیچ تغییر کدی** نصب PWA را کامل حفظ می‌کند
و مرز «تبلیغات (لندینگ)» و «ابزار درمانی (اپ)» را تمیز جدا می‌کند.

## پیش‌نیازها

- [ ] حساب در [hub.chabokan.net](https://hub.chabokan.net/fa) (اعتبار اولیهٔ رایگان دریافت می‌شود)
- [ ] خرید دامنه (از چابکان یا هر registrarium) — پیشنهاد: پسوند `.ir` برای مخاطب ایرانی
- [ ] ریپوی اپ روی گیت‌هاب: `github.com/AmirheydaripourOdin1133/rasa` (شاخهٔ main)
- [ ] در `rasa-standalone/index.html` عبارت `YOUR-DOMAIN` را با دامنهٔ واقعی جایگزین کرده باشید (۳ مورد — جست‌وجو کنید: `YOUR-DOMAIN`)

## سرویس ۱ — اپ PWA روی «هاست Next»

### ساخت سرویس

1. هاب چابکان ← **ساخت سرویس جدید** ← **هاست Next**
2. دیتاسنتر: **ایران** (تأخیر کم برای کاربران + اقامت دادهٔ سلامت داخل کشور)
3. پس از ساخت، از بخش تنظیمات: نسخهٔ Node = **22 (LTS)**

### منابع (پلن)

اسکریپت `build` پروژه (`next build --turbopack`) حافظهٔ قابل‌توجهی می‌خواهد:

| مسیر | پلن | توضیح |
|---|---|---|
| **الف) بیلد روی سرور** | حداقل **برنز (۱ گیگ RAM)** | ساده‌ترین؛ پلتفرم خودش `npm run build` و سپس `npm start` را اجرا می‌کند |
| **ب) بیلد لوکال، آپلود خروجی** | اقتصادی/پایه کافی است | روی سیستم خودتان `npm run build` بگیرید و پوشهٔ خروجی (به‌همراه `node_modules` production و `public`) آپلود کنید؛ سپس `START_COMMAND=npm start` |

برای شروع مسیر «الف» را پیشنهاد می‌کنیم؛ هر وقت مصرف بالا رفت از «تغییر منابع» افزایش دهید
(پرداخت ساعتی است و افزایش/کاهش لحظه‌ای بدون قطعی انجام می‌شود).

### دیپلوی از گیت

در کنسول وب ترمینال سرویس (بخش «کنسول» داشبورد):

```bash
rm -rf $(ls -A) 2>/dev/null
git clone https://github.com/AmirheydaripourOdin1133/rasa.git .
npm install
```

سپس از داشبورد سرویس **ری‌استارت** بزنید. پلتفرم طبق `package.json` اجرا می‌کند:

- `build` → `next build --turbopack`  (بار اول یا با دکمهٔ Build/ری‌استارت)
- `start` → `next start` (پورت ۳۰۰۰ — پیش‌فرض چابکان همان است)

### دامنه و SSL

1. داشبورد سرویس ← بخش **دامنه‌ها** ← افزودن `app.<دامنه>.ir`
2. در DNS دامنه، رکورد پیشنهادی پنل (A یا CNAME به سرویس) را ثبت کنید
3. SSL رایگان چابکان به‌صورت خودکار صادر و تمدید می‌شود — **HTTPS برای نصب PWA اجباری است؛ تا فعال شدنش تست نصب نکنید**

### بررسی سلامت اپ

- `https://app.<دامنه>.ir/manifest.webmanifest` → JSON مانیفست برگردد
- کنسول مرورگر بدون خطا؛ بنر «نصب رسا روی گوشی» در کروم اندروید ظاهر شود
- سافاری آیفون: منوی اشتراک ← «افزودن به صفحهٔ اصلی»
- بعد از نصب، اپ تمام‌صفحه (standalone) و آفلاین باز شود

## سرویس ۲ — لندینگ استاتیک روی دامنهٔ ریشه

> ⚠️ برای لندینگ **سرویس Node نخرید** — ۴ فایل استاتیک است.

1. هاب ← **ساخت سرویس جدید** ← **هاست استاتیک / ReactJS** (ارزان‌ترین پلن)
2. محتوای پوشهٔ `rasa-standalone` را آپلود کنید (فایل منیجر یا FTP):
   `index.html`، `css/`، `js/`، `assets/`، `logo.png`
3. دامنه‌های `<دامنه>.ir` و `www.<دامنه>.ir` را به سرویس وصل کنید → SSL خودکار
4. چک: دکمهٔ «ورود و نصب مستقیم اپلیکیشن» باید به `https://app.<دامنه>.ir/` برود

### به‌روزرسانی لندینگ

فایل‌ها را دوباره آپلود کنید؛ کش مرورگر برای HTML با یک رفرش ساده می‌شکند
(اگر لازم شد: Ctrl+F5). ریپوی گیت لندینگ هم جدا نگه‌داری می‌شود:

```
C:\Users\Amir\Desktop\rasa-standalone   (ریپوی گیت: Landing v1)
```

- [ ] اپ: onboarding کامل رد شود؛ تقویم شمسی در هر ۳ ورودی درست کار کند
- [ ] نصب PWA روی یک اندروید واقعی + یک آیفون واقعی تست شود
- [ ] حالت آفلاین: بعد از نصب، اپ با اینترنت قطع هم پوسته را باز می‌کند (سرویس‌ورکر `rasa-shell-v3`)
- [ ] دکمهٔ «اورژانس ۱۱۵» در اپ کار می‌کند (`tel:` link)

## به‌روزرسانی اپ (نسخه‌های بعدی)

```bash
# لوکال: تست کامل (typecheck + lint + test + build) → کامیت → پوش به گیت‌هاب
# روی چابکان (کنسول سرویس اپ):
```

توجه: اگر کش قدیمی دیدید، نام کش سرویس‌ورکر در `public/sw.js`
(`rasa-shell-v3`) را در نسخهٔ جدید bump کنید.

## نکات امنیتی و حریم خصوصی

- دادهٔ درمانی کاربران فقط روی دستگاه خودشان می‌ماند (localStorage) — سرور هیچ دادهٔ بالینی ذخیره نمی‌کند
- هیچ secret در ریپو نیست؛ بک‌اند Supabase عمداً وصل نیست و تا اتصال، متغیر محیطی لازم ندارید
- در صورت اتصال بک‌اند در آینده: کلیدها فقط در بخش «متغیرهای محیطی» داشبورد چابکان، هرگز در گیت

## هزینهٔ تقریبی (تومان/۳۰ روز — ایران، قبل از تخفیف دورهٔ پرداخت)

| سرویس | پلن | حدود هزینه |
|---|---|---|
| هاست Next (اپ) | برنز (۱GB) | ~۱٬۰۱۵٬۰۰۰ |
| هاست استاتیک (لندینگ) | کمترین پلن | ارزان‌تر از Node به‌مراتب |
| SSL + CDN | — | رایگان (با دامنهٔ چابکان) |

*تعرفه‌ها ممکن است تغییر کنند — رقم دقیق در هاب نمایش داده می‌شود. با «تست رایگان» و
اعتبار اولیه می‌توانید پیش از پرداخت، کل جریان را یک‌بار کامل تست کنید.*
